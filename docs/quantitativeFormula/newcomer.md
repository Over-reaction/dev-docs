# 新人入职量化公式

<NewcomerCalculator />

## 参数说明

| 符号 | 含义                   | 说明                                                                 |
| ---- | ---------------------- | -------------------------------------------------------------------- |
| B    | 基础熟悉时间           | 新人了解项目背景、搭建开发环境等基础准备所需的天数。                 |
| P    | 项目功能复杂度总分     | 整个项目全部功能按复杂度计分后的总和，单位为分。计分规则见下方备注。 |
| E    | 每天预计熟悉的功能分值 | 预计每天能熟悉多少分的功能，用于把总分换算成天数，单位为分/天。      |
| I    | 额外技术复杂度时间     | 熟悉项目中的额外技术难点所需的时间，按项目情况取 0 或 1 天。         |
| Tₘᵢₙ | 最短熟悉周期           | 预计熟悉周期的下限，单位为天。                                       |
| Tₘₐₓ | 最长常规熟悉周期       | 预计熟悉周期的上限，单位为天。                                       |
| T    | 预计熟悉周期           | 应用上下限后得到的预计天数。                                         |

## 公式含义

1. 用项目功能复杂度总分 `P` 除以每天预计熟悉的功能分值 `E`，将分值换算为天数。
2. 加上基础熟悉时间 `B`，然后向上取整。比如 3.25 天向上取整为 4 天。
3. 加上额外技术复杂度时间 `I`，根据项目情况取 0 或 1 天。
4. 以本次输入的最短熟悉周期 `Tmin` 和最长常规熟悉周期 `Tmax` 为上下限。计算值低于 `Tmin` 时取 `Tmin`，高于 `Tmax` 时取 `Tmax`，在范围内则取计算值。

::: info 备注：项目功能复杂度总分 P

以项目功能清单中的可独立验收功能为计分单位。参照下表评估复杂度，每项功能按符合的最高等级计一次分。

| 功能等级 | 功能数量 | 单个功能分值 | 前端评估标准                                           | 后端评估标准                                             |
| -------- | -------- | ------------ | ------------------------------------------------------ | -------------------------------------------------------- |
| 简单功能 | N₁       | 1 分         | 普通列表、详情、基础表单、简单交互                     | 单表 CRUD、普通查询、基础数据校验                        |
| 中等功能 | N₂       | 2 分         | 动态表单、组件联动、多状态交互、较复杂数据展示         | 多表关联、事务处理、较复杂条件查询、业务规则校验         |
| 复杂功能 | N₃       | 3 分         | 复杂表单、多步骤流程、可视化、跨系统交互、复杂状态管理 | 工作流、复杂业务计算、跨系统数据同步、复杂权限或并发处理 |

**P = N₁ × 1 + N₂ × 2 + N₃ × 3**

前端和后端分别参照对应的评估标准，采用相同的分值计算规则。填写 `P` 时，以整个项目的功能清单为准，汇总全部功能的分值。

:::
