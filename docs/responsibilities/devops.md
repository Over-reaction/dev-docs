## 一、岗位定位

负责公司业务系统及基础设施的部署、维护、监控、优化和安全管理，通过自动化运维、监控告警、故障处理和数据备份等手段，保障系统稳定、安全、持续运行，提高运维效率和资源利用率。同时承担分配的需求开发、功能优化和 BUG 修复任务。本文档只描述运维方面的职责，研发职责参考研发相关文档。

## 二、岗位职责

### 2.1 系统部署与维护

**工作职责：**

1. 负责 Linux、Windows 服务器的安装、环境配置、系统优化及日常维护。
2. 负责数据库、中间件、网络设备等基础设施的安装、配置、升级和维护。
3. 负责服务器运行环境、系统服务及相关依赖组件的管理。
4. 定期检查服务器资源、系统服务及基础设施运行状态，及时处理异常。
5. 维护系统部署配置及基础设施相关技术资料。

**工作产出：**

- 服务器环境配置清单
- 系统部署架构图
- 系统服务及依赖关系清单
- 日常运维记录

### 2.2 自动化运维+

**工作职责：**

1. 使用 Shell、Python 编写自动化运维脚本，减少重复性人工操作。
2. 使用 Ansible、SaltStack 等工具实现服务器批量配置、环境初始化及配置管理。
3. 使用 Jenkins、GitLab CI/CD 等工具建设自动化部署流程。
4. 实现应用部署、服务启停、日志清理、数据备份等运维任务自动化。
5. 维护自动化脚本及部署流程，确保执行过程可追踪、异常可定位。

**工作产出：**

- 自动化运维脚本
- 自动化部署配置
- 自动化运维执行记录
- 部署操作流程文档

### 2.3 系统监控与告警+

**工作职责：**

1. 建设服务器、网络、数据库、中间件及应用服务监控体系。
2. 通过 Zabbix、Prometheus 等工具监控 CPU、内存、磁盘、网络流量及服务运行状态。
3. 配置监控指标、告警阈值及异常通知机制。
4. 使用 ELK 等日志分析工具收集、检索和分析系统运行日志。
5. 及时响应监控告警，分析异常原因并跟踪处理结果。
6. 定期检查监控规则及告警有效性，优化监控配置。

**工作产出：**

- 系统监控配置及监控指标清单
- 监控告警规则
- 系统运行监控记录
- 异常告警处理记录

### 2.4 故障排查与恢复

**工作职责：**

1. 负责服务器、网络、数据库、中间件及应用运行环境故障排查。
2. 通过系统日志、应用日志、网络检测及资源分析定位故障原因。
3. 根据故障情况执行服务重启、配置修复、资源调整及数据恢复等操作。
4. 及时恢复异常服务，验证业务功能及系统运行状态。
5. 对重大故障进行原因分析，制定并落实预防措施。
6. 跟踪故障处理过程，形成完整的问题处理记录。

**工作产出：**

- 故障处理记录
- 故障原因分析报告
- 故障恢复记录
- 故障预防及优化措施

### 2.5 性能优化与资源管理+

**工作职责：**

1. 定期分析服务器、数据库、中间件及应用服务的运行性能。
2. 分析 CPU、内存、磁盘、网络及数据库等资源使用情况，识别性能瓶颈。
3. 优化数据库查询、服务配置、网络参数及系统运行环境。
4. 根据业务运行情况评估服务器资源需求，合理规划资源配置。
5. 持续跟踪优化效果，提高资源利用率及系统运行效率。

**工作产出：**

- 系统性能分析报告
- 服务器资源使用统计
- 性能优化记录
- 资源容量规划记录

### 2.6 安全与合规管理

**工作职责：**

1. 负责服务器操作系统、数据库及中间件安全配置和漏洞修复。
2. 管理服务器账号、访问权限及远程连接权限，落实最小权限原则。
3. 配置服务器防火墙、网络访问策略及安全防护规则。
4. 定期开展系统安全检查，排查弱口令、异常端口及不合理权限配置。
5. 配合开展安全审计及安全问题整改，保障系统运行环境安全。

**工作产出：**

- 系统安全检查记录
- 安全漏洞整改记录
- 服务器访问权限清单
- 安全配置及审计记录

### 2.7 数据备份与恢复

**工作职责：**

1. 制定数据库、文件及重要业务数据备份策略。
2. 配置自动化备份任务，明确备份周期、备份范围及数据保留期限。
3. 定期检查备份任务执行情况，确保备份数据完整、有效。
4. 根据业务需要执行数据恢复及灾难恢复操作。
5. 定期开展备份恢复验证和灾备演练，确保数据具备可恢复能力。

**工作产出：**

- 数据备份策略
- 自动化备份配置
- 数据备份执行记录
- 数据恢复验证报告
- 灾备演练记录

## 三、核心技能要求

| 技能类别        | 技能要求                                                 | 技术工具                              |
| --------------- | -------------------------------------------------------- | ------------------------------------- |
| 操作系统        | 熟悉 Linux、Windows 安装、配置、权限管理、进程及服务管理 | CentOS、Ubuntu、Windows Server        |
| 网络基础        | 掌握 TCP/IP、DNS、HTTP/HTTPS、端口及网络故障排查         | TCP/IP、DNS、防火墙                   |
| 脚本开发        | 能够编写、维护自动化运维脚本                             | Shell、Python                         |
| 监控与日志      | 能够搭建监控体系、配置告警及分析系统日志                 | Zabbix、Prometheus、ELK               |
| 数据库与中间件  | 掌握数据库及常见中间件的安装、配置、维护和故障排查       | MySQL、Redis、Nginx、LVS、HAProxy     |
| 云计算与容器+   | 熟悉容器化部署、容器资源管理及云平台基础运维             | Docker、Kubernetes、OpenStack、阿里云 |
| 自动化与 CI/CD+ | 掌握批量配置管理、自动化部署及持续集成流程               | Ansible、SaltStack、GitLab、Jenkins   |
| 消息及日志组件+ | 了解消息传递、日志采集及数据处理机制                     | Kafka                                 |

注：具体技术工具根据实际项目技术架构及运维环境确定，不要求所有项目同时使用全部工具。

## 四、岗位工作要求

1. 运维操作必须遵循规范流程，涉及系统配置、版本及运行环境变更时，应保留操作记录。
2. 生产环境重要变更应明确实施方案、影响范围及回退措施。
3. 监控告警必须及时响应，异常问题应持续跟踪直至恢复。
4. 自动化脚本必须具备必要的异常处理及执行日志。
5. 数据备份必须定期检查，并通过恢复验证确认备份有效性。
6. 系统安全问题及漏洞应及时排查和整改。
7. 故障处理完成后，应记录故障原因、处理过程及预防措施。
