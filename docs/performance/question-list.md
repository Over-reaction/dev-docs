# 问题清单类型合并

| 编号 | 问题大类 | 问题类型 | 分值 |
| --- | --- | --- | ---: |
| Q1 | 需求分析与产品设计问题 | 产品未理解客户需求、需求理解错误、功能设计未考虑全面、功能设计缺陷（产品）、业务变更 | / |
| Q2 | 研发设计与编码规范问题 | 功能设计缺陷（研发）、研发编码逻辑随意、工作粗心大意 | -15 |
| Q3 | 测试验证与质量控制问题 | 未完整测试、未横向功能验证、对接时未做三方数据校验、研发未进行数据校验 | -15 |
| Q4 | 研发流程执行问题 | 未按研发流程执行（未执行验证）、未按研发流程执行（未开需求评审会）、未按研发流程执行（未执行联调） | -15 |
| Q5 | 文档与交付质量问题 | 功能交付不清晰、未输出技术文档、研发文档缺失 | -10 |
| Q6 | 上线部署与生产运维问题 | 上线流程异常（数据初始化）、生产环境服务异常 | -25 |
| Q7 | 协同沟通与问题闭环问题 | 部门间协作信息不互通、问题处理未闭环 | -10 |
| Q8 | 研发任务未按要求实现 | 未执行 | -40 |
| Q9 | 外部因素及非责任问题 | 客户操作错误、客户网络环境不稳定、无问题 | 0 |
