# 测试缺陷等级量化标准

| 等级 | 严重程度 | bug判定标准                                                    | 界面交互判断标准                                                                                                                                   | 单次扣分 |
| ---- | -------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------: |
| S0   | 致命     | 核心业务完全无法运行、重要数据丢失、严重安全漏洞等             | 必要流程缺失：原型明确要求的必要操作步骤或功能未实现，导致整笔业务无法完成。如：缺少提交审批功能，业务无法发起；缺少审批功能，流程无法继续         |       40 |
| S1   | 严重     | 核心功能异常、业务结果错误、数据一致性错误、重要权限问题       | 独立功能缺失：原型明确要求的某项功能未实现，但业务主流程仍可完成。如：缺少导出、批量操作、附件预览等功能                                           |       25 |
| S2   | 一般     | 普通业务功能异常、参数校验错误、数据展示不正确、非核心功能失败 | 结构或交互偏差：功能已实现且结果正确，但字段配置、页面结构或操作方式与原型不一致。如：字段分组错误；弹窗编辑做成页面跳转；要求下拉选择却做成手动输 |       10 |
| S3   | 轻微     | 提示信息错误、非关键字段缺失、不影响业务的细节问题             | 视觉或文案偏差：功能、字段配置及操作方式均符合原型，仅展示细节不一致。如：字体、颜色、间距、对齐错误；文案存在错别字但不影响理解                   |        5 |
