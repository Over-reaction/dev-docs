# 前端开发标准

## 1. 文档说明

### 1.1 编写目的

为统一前端开发标准，规范团队代码编写方式，提高代码质量、可读性、可维护性及团队协作效率，特制定本标准。

本标准作为前端开发、代码审查及项目质量检查的参考依据。

### 1.2 适用范围

本标准适用于公司前端研发团队开发及维护的相关项目，包括但不限于：

- PC Web 管理系统
- H5 页面
- 微信小程序
- 其他前端相关项目

不同技术栈的项目，应遵循对应技术规范；通用规范适用于所有前端项目。

### 1.3 执行要求

- 新开发的项目及功能原则上应遵循本标准。
- 已有项目在维护、重构时逐步向本标准靠拢。
- 特殊业务场景无法遵循标准时，应在技术方案或代码审查中说明原因。
- 本标准未明确规定的内容，可参考项目现有规范及相关技术官方文档。

## 4. 维护说明

- 本标准由前端研发团队统一维护。
- 规范调整应经过团队讨论或技术评审后实施。
- 每次正式发布规范变更时，应同步更新版本号及修订记录。
- 各技术规范文件统一归属于《前端开发标准》，不单独维护文档版本号。
